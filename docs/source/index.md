## Features
- **Deterministic SQL Parsing & Query Verification**: Protect databases against unintended statements or unauthorized access patterns.
- **Payload Verification Endpoint**: Async-based FastAPI verification REST service.
- **MCP Wrapper support**: Secure database streams natively.
